# CS425: Database Organization – Summer 2024

This repository contains all my **homework assignments** for **CS425: Database Organization**, offered at **Illinois Institute of Technology** during **Summer 2024**.

The course provides a practical and theoretical foundation in relational database systems. Topics include data modeling with ER diagrams, functional dependencies and normalization, relational algebra, advanced SQL features, query optimization, transaction management, concurrency control, and recovery mechanisms.

All exercises and homework problems in this repository are guided by the following textbook:

> **Textbook**: *Database System Concepts*  
> **Authors**: Abraham Silberschatz, Henry F. Korth, S. Sudarshan  
> **Edition**: 7th Edition  
> 📚 *Published by McGraw-Hill, 2010*

## Key Concepts Covered

This course develops practical and analytical skills across these database topics:

- **Relational Data Modeling**  
  ER Diagrams, attributes, relationships, cardinality, weak/strong entities

- **Functional Dependencies & Normalization**  
  Determining FDs, candidate keys, 1NF to BCNF, and anomaly reduction

- **Relational Algebra**  
  Select, project, join, division, aggregation, set operations

- **SQL and Advanced SQL**  
  DDL/DML, joins, subqueries, grouping, constraints, window functions, OLAP queries

- **Database Architecture**  
  System components, schema levels, system catalogs

- **Query Processing & Optimization**  
  Query plans, cost estimation, heuristics, indexing strategies

- **Transactions & Concurrency**  
  ACID properties, schedules, locking, deadlock prevention

- **Recovery & Logging**  
  Write-ahead logging (WAL), checkpoints, undo/redo
